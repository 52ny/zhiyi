# 测试说明

## 测试分层

| 层级 | 工具 | 范围 | 位置 |
|---|---|---|---|
| 单元 | Vitest + jsdom | 纯函数、清洗、纠错、语言识别 | `tests/` |
| 工程校验 | Node 脚本 | 语法、资源引用、manifest、SW 清单 | `scripts/verify.mjs` |
| 手工回归 | 浏览器 | 导入、阅读、双语、复习、AI 降级 | 见下方清单 |

端到端自动化（Playwright）尚未接入，已列入路线图。

## 运行

```bash
npm test          # 单元测试
npm run verify    # 工程校验
npm run check     # lint + 单测 + 校验
```

## 现有单元测试

- 语言识别：英文、中文、文言文、现代文不误判。
- OCR 典籍纠错：空格合并、形近字、固定表述、标点规范化。
- 导入清洗：页码、广告、重复页眉；按“只要题目”筛选。
- 工具函数：`uid` 唯一性。

## 手工回归清单

1. 导入 PDF：分块、页码、目录正常。
2. 导入图片：预览显示置信度；低于 85% 自动 AI 校对可撤销。
3. 文言文：标签为「文言文」，开启双语输出白话文。
4. 点词：中文提示朗读，英文返回释义；「查询中」正确消失。
5. 复习：评分后到期时间变化，连续天数增加。
6. 演示模式：`?demo=1` 出现提示条并补齐 3 份示例资料。
7. AI 降级：断网时阅读、导图、复习仍可用，AI 给出可操作提示。
8. PWA：可安装；断网后仍能打开已缓存页面。
